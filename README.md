# Era Uma Vez Eu: histórias

Este é o conteúdo que o app **Era Uma Vez Eu** baixa pela internet. Ele é publicado pelo GitHub Pages em https://jheris-arch.github.io/era-uma-vez-eu-historias/

- `catalogo.json` traz a lista de histórias disponíveis, com o texto de cada uma.
- `historias/<id>/` guarda as ilustrações de cada história.

Não edite estes arquivos à mão. Eles são gerados pelo script `scripts/publicar-historias.js` do repositório do app. O passo a passo está em `conteudo/LEIA-ME.md`, também no repositório do app.
